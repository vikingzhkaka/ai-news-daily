可借鉴

Prompt / Context / Harness / Loop 四层 Agent 工程框架

Future AGI 梳理：Prompt（一句话怎么问清楚）→ Context（这轮给模型看什么）→ Harness（工具执行/重试/权限/预算）→ Loop（何时继续、何时停止）。Addy Osmani（6 月）命名 Loop engineering，Boris Cherny 称"我不再 prompt Claude，是让 loop 去 prompt 它"。

建议：落地 agent 先画清这四层边界，尤其 Harness 的权限 / 审批 / 预算护栏——模型说"该做什么"，Harness 决定"是否真被允许"。

Future AGI / Addy Osmani · 2026-08-15 · 链接

可借鉴

完整 Loop 九阶段（Discovery→Contract→…→Schedule）

一套受控系统方法论：发现上下文、明确任务契约、制定路径、执行、验证、有限修复、高风险交人（Human Gate）、沉淀经验、周期调度。关键区分：Prompt 描述规则，Harness 执行规则。

建议：把"高风险动作必须 Human Gate（展示动作/影响/证据/可恢复）"写进每个 agent 的任务契约，而非依赖模型自觉。

五大工程体系：Prompt / Context / Loop / Graph / Harness

本周主轴 · A1 集中化 vs 去中心化

本周 A1 被事件最强点燃：一边是 DeepSeek V4 Pro + Harness 开源、阿里首次开放 2.4T Max 级旗舰权重、Meta Muse Glimmer 30B 开源、智谱 GLM-5.3、Kimi K3 等国产开源密集连发；Hugging Face《State of Open Models》称中国开源模型下载占比 41% 首超美国、Qwen 家族上半年超 30 亿下载、衍生 15 万+。去中心侧在推的逻辑是"卖铲子"——模型越开放，算力/云需求越大；OpenRouter 周榜前五全中国模型、Top10 中国模型调用量 108.73T Token vs 美国 24.67T（差 4 倍以上）。集中侧（闭源）承压：Anthropic/OpenAI 靠垄断溢价，但开源以数分之一价格 + 本地私有化部署侵蚀其利润率与定价权；Counterpoint 警告若西方只顾围墙花园，开发者自然转向中国开放权重。为何重要：这把"资产协议化"（开源能力商品化）与 Viking 的 cargo/trust 二分法相连——能力正从少数闭源厂"集中"流向可被私有部署、可审计的"去中心"生态；对业务侧意味着核心场景定义权可握在自己手里（私有化 + 开放权重），而非被闭源 API 绑架。
